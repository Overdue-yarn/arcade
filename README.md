# Overdue Arcade

Eight 8-bit games for overdueyarn.com, in the Overdue palette (#fffaeb, #f6ebc8, #b9d4ea, #a9473f).

- `games/` — one self-contained HTML file per game (currently the playtest builds with a browser-only board).
- Leaderboard: Supabase project `egxmnrowhjdwaxiolhmh` (tables `periods`, `scores`; public access only through `submit_score`, `get_board`, `arcade_state`).
